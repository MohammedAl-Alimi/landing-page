# Landing Page

A responsive landing page built with plain HTML, CSS, and JavaScript — including
mobile-friendly layouts via dedicated media queries. No frameworks, no build step.

## Features

- Fully responsive design (`mediaqueries.css`)
- Clean, dependency-free HTML/CSS/JS
- Lightweight and fast to load

## Tech

- HTML5
- CSS3 (with responsive media queries)
- Vanilla JavaScript

## Run Locally

```bash
git clone https://github.com/MohammedAl-Alimi/landing-page.git
cd landing-page
open index.html
```
